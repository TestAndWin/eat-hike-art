# Fünf Giebel

Personal review website for restaurants, art exhibitions, and hiking tours in and around Lüneburg, Germany.

## Features

- **Restaurants**: Reviews with sub-ratings for service, food, ambiance, and value
- **Art**: Exhibition reviews with museum/gallery information
- **Tours**: Hiking and cycling tours with distance, duration, and difficulty
- **Rating System**: 1-5 Lüneburg Gables (half gables supported)
- **Admin Area**: Content management with draft/publish workflow
- **Voice-to-Publish**: Create entries via voice recording (planned)

## Tech Stack

- [Astro](https://astro.build/) with React Islands
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- File-based Markdown storage
- Self-hosted on Linux with Docker/Kubernetes

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
